# Тестовий план дій (демонстраційний)

Мета: показати, що агент уміє будувати план усередині чату й вести його по кроках.
Цей файл — шаблон. Його можна брати як зразок для справжніх задач.

## Задача
Перевірити, що проєкт встановлюється, синтаксис файлів цілий, тести проходять.

## Кроки

| # | Крок | Інструмент | Готово, коли |
|---|------|-----------|--------------|
| 1 | Перевірити синтаксис змінених Python-файлів | `python_check`, `run_command` | усі файли без помилок |
| 2 | Запустити юніт-тести | `run_command` (`python -m pytest -q`) | 0 failed |
| 3 | Перевірити, що сервер піднімається | `run_command` (запуск і швидка зупинка) | немає traceback |
| 4 | Перевірити роботу агента на простій задачі | `run_command` / `router:*` | відповідь без помилок |
| 5 | Зафіксувати результат | цей файл | таблиця нижче заповнена |

## Правила виконання
- Один крок — один виклик інструмента, без «пакетного» запуску всього.
- Якщо крок упав — спершу читаємо помилку, потім точкова правка, потім повторний запуск.
- Не оголошувати успіх, поки команда не повернула код 0.
- Зміни вносити мінімальні, точкові.
