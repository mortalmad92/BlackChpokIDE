## 2. Головна проблема: два раннери дають різні результати

Це знахідка №1, з неї починається весь план.

```
python -m unittest discover -s tests   →  148 тестів, OK
python tests/run_all.py                →  3 модулі ПРОВАЛЕНО
```

Розбіжність доведена запуском обох команд на одному коді. Причини:

1. `run_all.py` запускає частину тестів як **скрипти** (`python tests/test_commands.py`), де перевірки — це `print` + ручний лічильник, а не `unittest`. Такі «тести» не видно в `discover`, і навпаки.
2. `run_all.py` виставляє `BLACKCHPOK_HOME`, а `discover` — ні, тому частина тестів працює з різними даними.

### Наслідок: 3 реальні падіння, які ховаються за зеленим `discover`

| Модуль | Що впало | Причина |
| --- | --- | --- |
| `test_commands.py` | «є команда `/план`» | команду видалено з `slash_commands.COMMANDS`, тест лишився |
| `test_commands.py` | «група «Додати» є — 3» | очікує 4 команди, реально 3 |
| `test_work_log.py` | підписи «Читає / Шукає / Запускає» | у `work_log.TOOL_VIEWS` лишились англійські `Read file`, `Grep`, `Terminal` |
| `test_work_log.py` | таймер «міркую…» | код показує `Working…`, тест чекає українською |
| `test_tools_panel.py` | «панель має каталог — 19» | тест застарів на 11, реально 19 (правильно) |
