## Як вдалося прочитати

Публічна сторінка `/s/…` віддає лише клієнтську оболонку: HTML на 1.3 МБ без
розмітки діалогу. Текст лежить у вбудованих JSON-скриптах:

| Блок | Що всередині |
|---|---|
| `<script id="octane-conversation-transcript">` | 1 повідомлення асистента (142 КБ), зокрема `source.markdown`, `source.dil.constants` і `appData.opGenui.componentResults` |
| `<script id="__WEB_MOBILE_DATA__">` | `conversation.messages` — фактично порожній (`userMessageCount: 0`) |

`backend-api` і `backend-anon` віддають 401 — авторизація не потрібна лише для
самого HTML. Мова чату — українська, заголовок «Перегляньте цей чат».

**Важливо:** у шарі чату **немає повідомлень користувача й немає вкладеного
скриншота**. `userMessageCount = 0`, `attachments` відсутні. Тобто вихідний
скриншот BLACKCHPOK IDE, з якого почалася розмова, у цьому посиланні не
зберігся — видно лише відповідь ChatGPT на нього.

## Рекомендації з чату (стисло)

1. Гнучкі панелі з режимами робочого простору (розробка / агент / налагодження /
   компактний), зі збереженням розташування.
2. Читабельність: основний текст 13–14 px, панелі 12–13, другорядне 11–12, код
   13–14, заголовки 15–17; масштаб інтерфейсу окремо від масштабу коду.
3. Повноцінні повідомлення агента: Markdown, підсвітка коду, згортання викликів
   інструментів, індикатор «думає/виконує», час виконання, окремі помилки.
4. Центр контролю агента: стан, етап, активний інструмент, кроки, токени,
   швидкість, контекст, час; кнопка зупинки, що справді зупиняє роботу.
5. Git Diff: прийняти/відхилити окремий блок і всі зміни, до/після, лічильники,
   перелік файлів, відкат одного файла, позначка «ще не перевірено тестами».
6. Командна палітра для всіх функцій (`Ctrl+Shift+P`).
7. Єдина бокова панель із перемиканням розділів замість кількох колонок.
8. Адаптивність: 1366×768, 1920×1080, 2560×1440, масштаб Windows 100/125/150 %.

Порядок: P0 — неактивні/дубльовані кнопки, шрифти, компонування, центр
керування; P1 — чат і дії агента, черга, Git Diff, палітра, навігація; P2 —
режими, адаптивність, налаштування вигляду.

## Звірка з реальним кодом `blackchpok_ide/`

| Рекомендація | Стан у коді |
|---|---|
| Режими робочого простору | **є**: `layout_profiles.py` (5 профілів), зберігається в `userdata/layout.json` |
| Командна палітра | **є**: `palette.py`, `command_registry.py`, `Ctrl+Shift+P` |
| Смуга статистики (токени, кеш, заповнення) | **є**: `stats_bar.py` |
| Етапи виконання | **є**: `stage_strip.py` |
| Черга завдань із пауза/стоп/повтор | **є**: `task_center.py`, `queue_engine.py` |
| Список змін із переліком файлів | **є**: `changes_panel.py` (open / show diff / copy path) |
| Прийняти/відхилити зміни агента | **частково**: `live_edit.py` — лише для live-edit у редакторі; порізаного diff-review і відкату файла немає |
| Зупинка агента | **є**: `chat_panel.stop()` → `runner.cancel()` |
| Читабельність | **проблема підтверджена**: `theme.py` рахує `ui_base = size - 2`, тобто при типовому `font_size = 12` основний UI-текст стає 10 pt, другорядний 9 pt, найдрібніший 8 pt |
| Шрифт повідомлень чату | **дефект**: `theme.chat_body` (на 1 pt більший) оголошений, але в жодному модулі не використовується — чат малюється `chat_body`-ом лише за назвою, фактично `fonts.chat` |
| Окремий масштаб інтерфейсу | **немає**: у `UISettings` лише `font_size`, без `ui_scale` |
| Адаптивність / HiDPI | **немає**: у `main.py` і `main_window.py` немає `SetProcessDpiAwareness`, тому при масштабі Windows 125/150 % Tk малює дрібно й розмито |
| Єдина бокова панель | **частково**: `nav_sidebar.py` має розділи, але файли / контекст / зміни живуть окремими колонками праворуч |

## Що з цього пріоритетно (найдешевше й найпомітніше)

1. `SetProcessDpiAwareness` — один виклик, прибирає розмитість і дрібноту на HiDPI.
2. Перегляд формули шрифтів у `theme.Theme._build_fonts` (не `size - 2`, а
   базовий розмір для UI) + використати `chat_body` у стрічці діалогу.
3. Окреме `ui_scale` у `UISettings` + пункт у налаштуваннях.
4. Порізаний diff-review з прийняттям/відхиленням у `changes_panel.py`.
